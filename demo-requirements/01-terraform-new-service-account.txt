SERVICE ACCOUNT PROVISIONING REQUIREMENTS
=========================================
Document Type: Manual Build Specification
Target Environment: AWS GovCloud
Compliance: FedRAMP Moderate

OVERVIEW
--------
We need to provision a new AWS service account called "incident-response" 
that will be used by our security operations team. This account needs to 
follow our standard COOL account patterns.

REQUIRED COMPONENTS
-------------------

1. PROVISION ACCOUNT ROLE
   - Create an IAM role named "ProvisionAccount" 
   - This role should allow sufficient access to provision AWS resources
   - The role must be assumable from the Users account
   - Attach a policy allowing read access to the Lambda deployment bucket
     in the Terraform account

2. SNS NOTIFICATIONS
   - Create an SNS topic for CloudWatch alarms
   - Topic name: "cloudwatch-alarms"
   - Display name: "cloudwatch_alarms"
   - Subscribe the account email to this topic

3. USER/GROUP MODIFICATION ALERTS
   - Create an SNS topic that sends email whenever:
     * A new IAM or SSO user is created or deleted
     * A user is added or removed from a group
     * A group is created or deleted
   - Topic name: "user-or-group-modified"
   - Allow EventBridge to publish to this topic
   - Create an EventBridge rule to trigger on these events

4. INACTIVE USER MANAGEMENT
   - Deploy the Lambda function that disables inactive IAM users
   - Create an EventBridge rule that triggers on a fixed cadence
   - Lambda deployment package is in the Terraform account S3 bucket

5. BACKEND CONFIGURATION
   - Use S3 backend for Terraform state
   - Bucket: cisa-cool-terraform-state
   - DynamoDB table for state locking
   - Region: us-east-1

VARIABLES NEEDED
----------------
- users_account_id: The AWS account ID of the Users account
- lambda_bucket_name: S3 bucket containing Lambda packages
- lambda_key: S3 key for the disable-inactive-users Lambda
- aws_region: us-east-1

TAGGING REQUIREMENTS
--------------------
All resources must be tagged with:
- Project: COOL
- Environment: Production
- ManagedBy: Terraform
- Account: incident-response
